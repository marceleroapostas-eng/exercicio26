# Exercício 26 - Numeros pares

## Descrição

O programa utiliza a estrutura de repetição `while` para imprimir os números de 34 até 56, aumentando o valor em 2 a cada repetição.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

Este programa não possui entrada de dados.

## Saída

O programa imprime os números de 34 até 56, de 2 em 2, cada um em uma linha.
